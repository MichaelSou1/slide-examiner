\subsection{Exact evaluated prompt templates}\label{app:slideaudit-prompts}

The following are the complete textual templates used by the two conditions;
the image occupies the indicated image part. Bracketed fields are populated
from each manifest record. C0 receives all nine page candidates in one call.

{\footnotesize\ttfamily\raggedright
\noindent\textbf{C0 system}\par
You are a slide quality examiner. Inspect the given single slide page for the
requested page-scoped defect types. Output ONLY one valid JSON object matching
PageExamResult. No prose, no code fences.\par
\medskip
\noindent\textbf{C0 user}\par
[IMAGE]\par
PAGE\_ID: [page\_id]\par
render=[image\_width\_px]x[image\_height\_px]
scale=([scale\_x],[scale\_y]) dpi=[dpi] renderer=[renderer]\par
SCENE: [scene]\par
TEMPLATE\_ID: [template\_id]\par
PAGE\_INDEX: [page\_index]\par
TASK\_BRIEF: [task\_brief]\par
CHECK\_SCOPE: ['G1\_TEXT\_OVERFLOW', 'G2\_ELEMENT\_OVERLAP',
'G3\_ALIGNMENT\_OFFSET', 'G4\_FONT\_SIZE\_INCONSISTENCY',
'G5\_BRAND\_COLOR\_VIOLATION', 'G6\_MARGIN\_VIOLATION',
'S1\_TITLE\_BODY\_MISMATCH', 'S4\_DENSITY\_RULE\_VIOLATION',
'S6\_IMAGE\_TEXT\_CONTRADICTION']\par
TASK: Decide for each candidate type whether the defect is PRESENT.\par
Consider ONLY these candidate defect types:\par
G1\_TEXT\_OVERFLOW: text overflows or spills beyond the bounds of its box/placeholder;\par
G2\_ELEMENT\_OVERLAP: two elements visually overlap or collide when they should not;\par
G3\_ALIGNMENT\_OFFSET: an element is misaligned / offset from where it should sit;\par
G4\_FONT\_SIZE\_INCONSISTENCY: inconsistent font sizes among text that should match;\par
G5\_BRAND\_COLOR\_VIOLATION: a color is off-brand / wrong for an element;\par
G6\_MARGIN\_VIOLATION: an element bleeds past the page margin or off the canvas edge;\par
S1\_TITLE\_BODY\_MISMATCH: the slide title does not match the body content / topic;\par
S4\_DENSITY\_RULE\_VIOLATION: the slide is overcrowded / too dense with text;\par
S6\_IMAGE\_TEXT\_CONTRADICTION: the image content contradicts the slide text.\par
Report a finding only when you are confident the defect is actually present.\par
Output ONLY one JSON object (no prose, no code fences) matching:\par
\{``has\_defect'': <bool>, ``findings'': [\{``type'': ``<one candidate ID>'',
``severity'': ``minor|moderate|severe'', ``locator'': \{``level'': ``page'',
``page\_id'': ``<id>'', ``element\_id'': ``<id-or-null>'',
``related\_page\_ids'': []\}, ``evidence'': ``<short grounded reason>'',
``fix\_suggestion'': ``<one executable action>''\}]\}\par
If the slide/deck is clean, output
\{``has\_defect'': false, ``findings'': []\}.\par
\medskip
\noindent\textbf{C3 system}\par
You are a meticulous slide-quality inspector. You will be asked about ONE
specific possible defect. Look only at what is visibly rendered. Answer with a
single JSON object and nothing else.\par
\medskip
\noindent\textbf{C3 user}\par
[IMAGE]\par
Question: [one question from the list below]\par
Answer strictly as JSON:\par
\{``present'': true|false, ``evidence\_element'': ``<concrete element/region you
point to, or empty>'', ``evidence\_region'': ``<top-left|top|top-right|left|
center|right|bottom-left|bottom|bottom-right|empty>'', ``confidence'': 0.0--1.0\}\par
If present=true you MUST name a concrete evidence\_element (e.g. ``the title'',
``the right-hand card'', ``the bottom list item''). If you cannot point to
concrete visible evidence, answer present=false.\par
}

The instantiated C3 question for each evaluated class was:
\begin{itemize}\footnotesize
\item \g{G1}: Does any text visibly overflow or get clipped by its text box---letters cut off at an edge, or a line running past the box boundary?
\item \g{G2}: Does this slide visibly exhibit the following defect---Two non-background elements overlap.?
\item \g{G3}: Among a list of bullet/body items that should line up, is ONE of them misaligned---indented or shifted so it does not line up with the rest?
\item \g{G4}: Does this slide visibly exhibit the following defect---Same-level text uses inconsistent font sizes.?
\item \g{G5}: Among a list of bullet/body items that share one text colour, does ONE of them have a text colour that clearly differs from the others?
\item \g{G6}: Is the slide's whole block of content shifted toward one side, leaving clearly unequal left/right margins---one side crowded against (or running off) the edge while the opposite side is noticeably empty?
\item \g{S4}: Does this slide visibly exhibit the following defect---Text density exceeds a scenario-specific rule.?
\end{itemize}

\section{Repeated whole-rubric control across three vendors}
\label{app:compute-control}
% =====================================================================

The main paper compares one atomic \g{G7} query (C3) against ten independent
whole-rubric C0 samples. Table~\ref{tab:compute-control} gives the complete
three-vendor result, including two prespecified companion aggregations that are
not headline results in the main paper. \emph{Self-consistency} is majority
vote over the repeated C0 samples. \emph{Union} flags a slide when any C0 draw
flags it; this OR rule relaxes the decision threshold as the number of draws
grows and is therefore not a standard accuracy-oriented compute-scaling rule.
\emph{C0-full} is a single whole-taxonomy call supplied with per-class
definitions and required evidence. All conditions use the same rendered pairs,
and balanced accuracy is computed against paired clean controls.

\section{Diagnosis--method correspondence, frozen confirmation, and extreme-offset addenda}
\label{app:w5-heldout}

\paragraph{Scoring units, intervals, and multiplicity.}
A paired clean/defective slide is the basic scoring unit throughout the paired
image experiments. In 2-AFC controls, presenting both orders is an order-bias
check on the same pair, not two independent defect instances. Balanced accuracy
is the mean of recall and specificity; its bracketed interval is
\emph{component-wise Wilson-derived}, obtained by averaging the Wilson bounds
for those two binomial components. Precision, recall, and specificity intervals
are ordinary Wilson intervals for their corresponding counts. We do not attach
a macro confidence interval: the current analysis lacks system-level uncertainty
clustered by template or deck.

The paper-wide primary correction family contains 85 reported significance
tests: the original 61 elicitation, examiner, and reward tests plus all 24
contrasts from the repeated-C0 control analysis. At $\alpha=0.05$, 35 survive
Holm (FWER) and 47 survive Benjamini--Hochberg (FDR); the released
\path{data/part3/p3_multiplicity.json} records every raw and adjusted
$p$-value. The 24-test within-analysis family is retained only as a focused,
descriptive companion, not as the paper-wide primary family. The repeated-C0
control uses ten samples and therefore receives more inference budget than the
single C3 call; it tests whether extra sampling can explain the C3 recovery and
does not assert equal compute budgets.
